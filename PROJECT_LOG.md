# Project Log

## Context

- Goal: create a small birthday web card for Savely, opened by QR code from a perfume gift.
- Theme: cozy pixel farming RPG inspired, nostalgic, warm, not a direct copy of any specific game assets.
- Gift flow: perfume first, hidden Steam reward shown as a quest ticket instruction.
- Constraint: static site only, suitable for GitHub Pages, no server or database.
- Safety decision: do not store a real Steam code or account-specific information on the site.
