# Day 1, Year 1

Static birthday quest card for Savely.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Publish

The site is designed for GitHub Pages. After pushing to GitHub, enable Pages for the `main` branch and root folder.

## Notes

- No original game assets are used.
- The Steam reward is represented as an instruction, not as a stored code.
- The site uses Google Fonts: `Pixelify Sans` for readable pixel text and `Press Start 2P` for UI accents.
